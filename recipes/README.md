# 🍚 공주님 집밥 자동화 레시피 DB

만개의레시피에서 큐레이션한 공주님 전용 레시피 모음과 매일 저녁 메뉴 자동 추천 시스템.

**라이브 데모:** https://kwak8711.github.io/recipes/

## 📁 구조

```
recipes/
├── index.html          # 오늘 저녁 뭐 먹지? 인터랙티브 선택기 (GitHub Pages)
├── data/
│   └── recipes.json    # 레시피 마스터 DB (API 역할)
├── md/
│   ├── 7008508-김치규동.md
│   ├── 6838094-밥도둑소고기볶음고추장.md
│   └── 6922749-차돌박이된장찌개.md
└── apps-script/
    └── daily-picker.gs # 매일 저녁 Slack 자동 추천 (Google Apps Script)
```

## 🎯 기능

### 1. 웹 선택기 (index.html)
- 📱 모바일 최적화
- 🎲 3개 랜덤 추천 → 선택
- 🏷 필터: 혼밥 / 쌀쌀한날 / 손님맞이 / 밥도둑 / 20분이내
- 📅 로컬 선택 기록 (localStorage, 최근 14일)
- 📝 재료·조리순서·꿀팁 상세 모달

### 2. Slack 매일 알림 (apps-script/daily-picker.gs)
- ⏰ 매일 평일 18:00 자동 발송
- 🎲 랜덤 3개 선택지 → Slack에서 투표/선택
- 🧾 선택 로그 Google Sheets 자동 저장
- 🎨 날씨·요일별 가중치 (쌀쌀한 날 → 찌개 가중, 평일 → 20분이내 가중)

## 📥 레시피 추가 방법

### 방법 1: 수동 추가
1. `data/recipes.json`에 새 레시피 객체 추가
2. `md/<id>-<이름>.md` 파일 생성
3. 커밋 & 푸시 → GitHub Pages 자동 반영

### 방법 2: 자동 파싱 (Apps Script)
```
GAS 메뉴 → 🍚 레시피 → URL로 추가하기
→ 만개의레시피 URL 붙여넣기 → recipes.json 자동 PR 생성
```
