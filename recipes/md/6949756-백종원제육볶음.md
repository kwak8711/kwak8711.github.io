# 🔥 백종원 제육볶음 황금레시피

**출처:** [만개의레시피 6949756](https://www.10000recipe.com/recipe/6949756) · 빈빈자매맘 (조회수 18,192)
**분량:** 6인분+ · **조리시간:** 30분 · **난이도:** 쉬움 (★★☆☆☆)
**태그:** `#제육볶음` `#돼지고기` `#매운맛` `#밥도둑` `#백종원` `#안주`

## 재료
### 본재료
- 돼지고기 앞다리살 600g
- 당근 1/2개
- 양파 1개
- 양송이버섯 5개
- 청양고추 3개
- 다진 파 적당량

### 양념
- 진간장 3T
- 고추장 2T
- 다진마늘 2T
- 물 150ml
- 설탕 3T
- 고춧가루 3T
- 올리브유 3T
- 참기름 1T
- 후추·통깨 약간

## 조리순서
1. **야채 손질** - 당근 채썰고, 양파 채썰고, 양송이·청양고추 다지기
2. **양념장 미리 준비** - 진간장 3T + 고추장 2T + 다진마늘 2T + 물 150ml
3. **파기름 내기** - 넓은 웍에 다진 파 + 올리브유 3T → 중불
4. **고기 볶기** - 센불에서 볶으면서 한입 크기로 자르기
5. **설탕 투입** - 설탕 3T 넣고 한번 더 볶기 (누린내 제거!)
6. **양념 추가** - 양념장 + 고춧가루 3T 투입, 양념 스며들게
7. **야채 투입** - 센불로 야채 넣고 볶기 + 후추 톡톡
8. **마무리** - 자박하게 졸아들면 참기름 1T + 통깨

## 꿀팁
- **핵심:** 센불로 휘리릭 볶기
- **매콤 UP:** 김치 살짝 썰어 넣기
- **향긋 UP:** 깻잎 추가 (인기 후기)
- **안주 궁합:** 소주 👍
- **담백 버전:** 참기름 생략

**예상비용:** ₩2,500/인분
