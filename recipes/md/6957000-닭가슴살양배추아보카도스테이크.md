# 🥗 닭가슴살 양배추 아보카도 스테이크

**출처:** [만개의레시피 6957000](https://www.10000recipe.com/recipe/6957000) · 지니어트
**분량:** 1인분 · **조리시간:** 20분 · **난이도:** 초급 (★★☆☆☆)
**영양:** 🟠 **410kcal**/인분 (중칼로리)
**태그:** `#건강식` `#닭가슴살` `#아보카도` `#양배추` `#저탄수화물`

## 재료
- 닭가슴살 150g
- 양배추 (큰 조각) 100g
- 아보카도 0.5개
- 올리브유 2T
- 소금 약간
- 후추 약간
- 레몬즙 1T
- 발사믹 글레이즈 1T

## 조리순서
1. 닭가슴살 소금·후추 밑간 (10분)
2. 양배추 큰 조각으로 썰기 (스테이크 느낌)
3. 팬에 올리브유 두르고 양배추 노릇하게 굽기
4. 꺼내고 같은 팬에 닭가슴살 양면 노릇하게
5. 아보카도 반 썰어 접시에 올리기
6. 구운 양배추+닭가슴살 올리고 레몬즙·발사믹 글레이즈

## 꿀팁
- 저탄수 고단백 완전체
- 아보카도의 건강한 지방 + 닭 단백질 + 양배추 식이섬유
- 운동 후 식사로 최적
- 굽는 순서: 양배추 → 닭 (기름 재활용)

**예상비용:** ₩7,000/인분
