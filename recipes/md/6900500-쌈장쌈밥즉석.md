# 🥗 쌈장 쌈밥 (즉석)

**출처:** [만개의레시피 6900500](https://www.10000recipe.com/recipe/6900500) · 공주님 특선
**분량:** 2인분 · **조리시간:** 10분 · **난이도:** 매우쉬움 (★☆☆☆☆)
**영양:** 🟡 **380kcal**/인분 (중저칼로리)
**태그:** `#쌈밥` `#쌈장` `#건강식` `#간편` `#채식가능`
🏠 **공주님 pantry 매칭!**

## 재료
- 상추 10장
- 깻잎 5장
- 밥 1공기
- 쌈장 2T
- 계란 (프라이) 1개
- 베이컨 (구움) 2줄
- 양파 (채썬) 0.25개
- 참기름 0.5T

## 조리순서
1. 상추·깻잎 깨끗이 씻기
2. 밥에 참기름 살짝 비비기
3. 베이컨 바삭하게 굽고 1cm로 자르기
4. 계란 반숙 프라이
5. 상추 → 깻잎 → 밥 → 베이컨 → 양파 → 쌈장 → 쌈
6. 계란 반숙 터뜨려 함께

## 꿀팁
- 쌈장은 집마다 다르니 1T부터 시작
- 밥을 참기름에 비비면 쌈이 더 고소
- 공주님 pantry: 쌈장·계란·베이컨·양파 ✅ (4/4 매치!)
- 구운 삼겹살 추가하면 완전체

**예상비용:** ₩2,000/인분
