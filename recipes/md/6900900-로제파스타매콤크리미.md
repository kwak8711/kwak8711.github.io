# 🍜 로제 파스타 (매콤 크리미)

**출처:** [만개의레시피 6900900](https://www.10000recipe.com/recipe/6900900) · 공주님 특선
**분량:** 2인분 · **조리시간:** 20분 · **난이도:** 쉬움 (★★☆☆☆)
**영양:** 🔴 **620kcal**/인분 (고칼로리)
**태그:** `#파스타` `#로제` `#크림` `#매콤` `#분위기`
🏠 **공주님 pantry 매칭!**

## 재료
- 스파게티 면 200g
- 로제 스파게티 소스 400g
- 쫄깃한 베이컨 100g
- 양파 0.5개
- 우유 50ml
- 올리브오일 2T
- 다진마늘 1T
- 파마산치즈 3T
- 페페론치노 3개
- 소금 1T
- 후추 약간

## 조리순서
1. 소금 1T + 끓는 물에 스파게티 7-8분
2. 양파 채썰고 베이컨 1cm 폭
3. 팬에 올리브오일 + 마늘 → 베이컨 → 양파 순서
4. 양파 투명해지면 로제 소스 투입
5. 우유 50ml 추가 (더 크리미하게)
6. 페페론치노 (매콤)
7. 건진 면 + 면수 3T 넣고 토스
8. 파마산 듬뿍 + 후추

## 꿀팁
- 우유 추가로 더 부드럽게
- 치즈 많이 넣으면 리조또 느낌
- 공주님 pantry 100% 매칭: 로제소스·베이컨·양파·올리브오일 ✅
