# 🔥 백종원 제육볶음 황금레시피

**출처:** [만개의레시피 6949756](https://www.10000recipe.com/recipe/6949756) · 빈빈자매맘
**분량:** 6인분 · **조리시간:** 30분 · **난이도:** 쉬움 (★★☆☆☆)
**영양:** 🟠 **450kcal**/인분 (중칼로리)
**태그:** `#제육볶음` `#돼지고기` `#매운맛` `#밥도둑` `#백종원`

## 재료
- 돼지고기 앞다리살 600g
- 당근 0.5개
- 양파 1개
- 양송이버섯 5개
- 청양고추 3개
- 다진 파 적당량
- 진간장 3T
- 고추장 2T
- 다진마늘 2T
- 물 150ml
- 설탕 3T
- 고춧가루 3T
- 올리브유 3T
- 참기름 1T
- 후추 약간
- 통깨 약간

## 조리순서
1. 당근·양파 채썰고, 양송이 5개·청양고추 3개 다지기
2. 양념장 미리 섞기: 진간장 3T + 고추장 2T + 다진마늘 2T + 물 150ml
3. 넓은 웍에 다진 파 + 올리브유 3T 넣고 파기름 내기
4. 고기 넣고 센불에 볶으면서 한입 크기로 자르기
5. 설탕 3T 넣고 한번 더 볶기 (돼지 누린내 제거)
6. 양념장 + 고춧가루 3T 추가, 양념 스며들게 볶기
7. 야채 투입 후 센불로 볶기 → 후추 톡톡
8. 양념물 자박하게 졸아들면 참기름 1T + 통깨로 마무리

## 꿀팁
- 센불로 휘리릭 볶는 게 핵심
- 매콤함 UP: 김치 살짝 썰어 넣기
- 깻잎 추가하면 향긋함 UP (후기)
- 안주로도 최고 - 소주와 궁합 👍
- 참기름 생략하면 담백한 버전

**예상비용:** ₩2,500/인분
