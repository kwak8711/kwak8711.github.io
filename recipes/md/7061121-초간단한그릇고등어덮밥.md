# 🍚 초간단 한그릇 고등어덮밥

**출처:** [만개의레시피 7061121](https://www.10000recipe.com/recipe/7061121) · 모닝
**분량:** 1인분 · **조리시간:** 5분 · **난이도:** 매우쉬움 (★☆☆☆☆)
**태그:** `#덮밥` `#고등어` `#5분요리` `#혼밥` `#자취생`

## 재료
- 시판용 고등어구이 1토막
- 밥 (뜨거운 밥) 1공기
- 참기름 (or 들기름) 1T
- 간장 1T
- 김 (선택) 1장
- 통깨 약간

## 조리순서
1. 그릇에 참기름 1T + 간장 1T (1:1 비율)
2. 양념 위에 밥 올리기 (골고루 비벼짐)
3. 전자레인지 1분으로 데운 고등어구이 올리기
4. 비벼서 완성!

## 꿀팁
- 참기름 = 진한맛 / 들기름 = 고소한맛
- 김·김치 곁들이면 더 맛있음
- 시판 고등어구이면 어떤 브랜드도 OK
- 진짜 5분 완성 (바쁜 아침에 👍)

**예상비용:** ₩3,500/인분
